# Working Preferences for David McAughtry

1. **One Step at a Time for User Actions:** Whenever the user needs to perform manual actions (e.g., creating a GitHub repo, configuring Google Cloud Console, changing settings, or signing in), give **only one single step at a time**. Wait for the user to confirm that step is done before giving the next step — never present a long multi-step list that requires scrolling back up.
2. **Live Checklist on Multi-Step Agent Tasks:** For any multi-step task the agent carries out, immediately create a live checklist of steps and give a brief 1–2 sentence update as each step finishes.
